# Karunya-
AI-based detection and classification of industrial fires and persistent thermal sources using NASA FIRMS and OpenStreetMap.

## How it works
1. Collect thermal hotspots from NASA FIRMS
2. Process data with Python & Pandas
3. Detect unusual heat near industrial zones
4. Classify as potential fire, persistent source or anomaly
5. Track persistence of recurring hotspots
6. Map to nearby industry and land use via OpenStreetMap
7. Score risk as Low, Medium or High
8. Monitor on a dashboard with alerts

## Tech Stack
Python · Pandas · ML · NASA FIRMS (VIIRS) · OpenStreetMap
